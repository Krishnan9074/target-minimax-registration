# Data

`L1-L2.med` is the finite-element mesh of the upper lumbar spine published on
Zenodo, [doi:10.5281/zenodo.3961334](https://doi.org/10.5281/zenodo.3961334),
licensed **CC-BY-4.0**. It is redistributed here unmodified, with attribution
to its original authors.

Only the rigid geometry of the L1 vertebra (node families 4, 5 and 8 of the MED
file) is used, via `tmr/anatomy.py`. No material model, no simulation output
and no patient data are used.
